# Project descriptions for applications

Use only the projects whose code and decisions you can explain. These are project summaries, not a claim of unaided authorship or paid client work.

## German

**Phone Catalog — React, TypeScript, Redux Toolkit**  
Shop-Frontend mit Produktvarianten, URL-basierter Sortierung und Pagination sowie persistentem Warenkorb und Favoriten. Statische Produktdaten; Lernprojekt ohne Zahlungsbackend.

**PromptGuard UI — React, Vite, REST-Anbindung**  
Frontend-Beitrag zu einem Teamprojekt: Chat, Darstellung von Guardrail-Ergebnissen, markierte Textfragmente und Vorfallübersicht. Eigenständiger Demomodus mit simulierten Ergebnissen.

**FORNO — HTML, CSS, JavaScript**  
Responsives Restaurantkonzept auf Deutsch und Englisch mit redaktionellem Layout und zugänglichen Zutaten-Akkordeons. Fiktives Restaurant als Portfolioentwurf.

**SupportDesk Lite — Python, SQLite, JavaScript**  
Lokale IT-Ticketverwaltung mit JSON-API, SQLite-Persistenz und Browser-Dashboard. Neue Portfoliodemo für API- und Datenbankabläufe; kein produktives Ticketsystem.

## English

**Phone Catalog — React, TypeScript, Redux Toolkit**  
Storefront frontend with product variants, URL-based sorting and pagination, and persistent cart and favourites. Learning project using static product data; no payment backend.

**PromptGuard UI — React, Vite, REST integration**  
Frontend contribution to a team project: chat, guardrail verdict presentation, highlighted fragments and incident views. Standalone demo uses simulated verdicts.

**FORNO — HTML, CSS, JavaScript**  
Responsive German / English restaurant concept with an editorial layout and accessible ingredient accordions. A fictional venue created for the portfolio.

**SupportDesk Lite — Python, SQLite, JavaScript**  
Local IT-ticket application with a JSON API, SQLite persistence and browser dashboard. A new portfolio demo for API and database workflows; not a production service.
